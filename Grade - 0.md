# 1. LITERACY, PHONICS & READING

## 🎯 What This Builds
Letter recognition · letter-sound knowledge · phonemic awareness · blending · decoding · vocabulary · comprehension · storytelling · listening

---

## ⭐ PRIMARY WORKBOOKS

### 1. Explode the Code — *Get Ready for the Code* (Primers A, B, C)

| Detail | Info |
|---|---|
| **Best for** | Ages 3–5, pre-K and K |
| **What it teaches** | Lowercase letter forms, initial consonant sounds, fine-motor tracing, left-to-right tracking, sound-to-letter matching |
| **Why it works** | No visual overwhelm. One sound at a time. Pencil control built in. |
| **How to use** | **1 page per day maximum** — half a page is fine for a 3-year-old |
| **Cost** | ~$8–12 per book, or ~$25 for the 3-book bundle |
| **Where** | Amazon, Rainbow Resource, Christianbook, Homeschool Hive |

### 2. Bob Books — Set 1: Beginning Readers

| Detail | Info |
|---|---|
| **Best for** | Ages 3–5 (once they know a few letter sounds) |
| **What it teaches** | Finger-pointing, tracking print, blending 2–3 sound CVC words (*mat, sat, Sam*) |
| **Why it works** | Introduces only **4 sounds at a time** (*m, a, t, s*). Child reads a **complete book on day one**. Zero guessing. |
| **How to use** | 1 mini-story per day (5 min). Child slides finger under each word. |
| **Cost** | ~$15–18 for the 12-book box set |
| **Where** | Amazon, Bob Books official site, most bookstores |

### 3. Logic of English — Foundations A

| Detail | Info |
|---|---|
| **Best for** | Ages 4–7, a **more comprehensive alternative** to combining multiple workbooks |
| **What it teaches** | Multi-sensory phonics linking letter sounds with gross-motor games and sandpaper letter tracing |
| **Why it works** | Full curriculum in one box — teacher manual, student workbook, phonogram cards, sandpaper letters, and games |
| **How to use** | 15–20 min/day, follows a scripted teacher manual |
| **Cost** | ~$150–200 for the full set (investment level) |
| **Where** | Logic of English official site |

### 4. Kumon — *My Book of Rhyming Words* & *Alphabet Games*

| Detail | Info |
|---|---|
| **Best for** | Ages 3–5 |
| **What it teaches** | Repetitive, tactile line-drawing and letter-sound association |
| **Why it works** | Kumon's incremental method builds confidence through tiny steps |
| **Cost** | ~$7–9 each |
| **Where** | Amazon, Kumon centers, bookstores |

### 5. Oxford Reading Tree (supplementary readers)

| Detail | Info |
|---|---|
| **Best for** | Ages 4–6, after Bob Books Set 1 |
| **What it teaches** | Graded reading progression with beloved characters (Biff, Chip, Kipper) |
| **Cost** | Varies; libraries often carry these |
| **Where** | Library, Amazon, Oxford Owl (free eBooks online) |

## 🎯 THE FOUR SCIENCE QUESTIONS (Ask Every Time)

1. **"What do you think will happen?"** → Prediction
2. **"Why did it happen?"** → Reasoning
3. **"What changed?"** → Observation
4. **"How can we test it again?"** → Experimentation

**One science experiment per week is enough.** The questions matter more than the activity.
